# stone_equality
Allows for most stones to be used in cobblestone crafting recipes.

### Explanation
Allows most stones to be used in cobblestone crafting recipes like : 
- Stone Tools
- Stone Weapons
- Furnace
- Lever
- Brewing Stand
- Dispenser
- Dropper
- Observer
- Piston

### Stones in the recipe
- andesite
- basalt
- blackstone
- cobblestone
- cobbled_deepslate
- deepslate
- diorite
- end_stone
- granite
- tuff
- stone
